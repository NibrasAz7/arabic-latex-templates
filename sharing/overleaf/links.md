# Overleaf One-Click Links

Each link below opens a **ready-to-edit copy** of the template in Overleaf - no LaTeX install required.

> **How this works:** The ZIPs are stored in the zips/ folder of this repo. Click any link to open in Overleaf.
>
> **Note:** The Overleaf API uses the snip_uri parameter pointing to a ZIP file URL. The ZIP must be publicly accessible.
