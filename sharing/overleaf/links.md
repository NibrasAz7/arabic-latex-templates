# Overleaf One-Click Links

Each link below opens a **ready-to-edit copy** of the template in Overleaf — no LaTeX install required.

> **How this works:** The ZIPs are built by GitHub Actions and attached to the [1.0.0 release]https://github.com/NibrasAz7/arabic-latex-templates/releases/tag/v1.0.0) as assets. Click any link to open in Overleaf.
>
> **Setup:**
> 1. Replace NibrasAz7 with your GitHub username
> 2. Publish a GitHub Release tagged 1.0.0 — the CI workflow auto-builds and attaches all 91 ZIPs
> 3. Share these links anywhere
